PowerShell Ingestion Pipeline

Local Excel/CSV to JSON Converter Engine

This script imports PowerBI CSV exports and updates the local JS data file (data.js) consumed directly by this HTML file without a web server. 

# PowerShell Script: Sync-QAData.ps1
$csvPath = ".\PowerBI_Exports\QA_Metrics.csv"
$jsPath  = ".\data.js"

Write-Host "[RUN] Processing raw audit data..." -ForegroundColor Cyan
$data = Import-Csv -Path $csvPath
$json = $data | ConvertTo-Json -Depth 4 -Compress
$jsContent = "window.dashboardData = $json;"

Set-Content -Path $jsPath -Value $jsContent -Encoding UTF8
Write-Host "[SUCCESS] data.js generated successfully!" -ForegroundColor Green
