PowerShell Data Pipeline Engine

Excel / CSV to JSON JavaScript Data File Converter

Architecture Note: Below is the actual PowerShell script used to bridge PowerBI Excel/CSV exports into the frontend data.js file formatted as window.dashboardData = [...].

Generate-DataJS.ps1 
# -------------------------------------------------------------
# POWERSHELL INTERPRETER SCRIPT: CSV -> JS DATASET
# -------------------------------------------------------------

$csvPath  = ".\Exports\PowerBI_Quality_Export.csv"
$jsOutputPath = ".\data.js"

# 1. Import raw data from PowerBI CSV Export
Write-Host "[INFO] Reading raw quality metrics..." -ForegroundColor Cyan
$rawData = Import-Csv -Path $csvPath

# 2. Convert CSV objects directly to JSON structure
$jsonPayload = $rawData | ConvertTo-Json -Depth 5 -Compress

# 3. Format as a global JS variable to allow serverless opening
$jsContent = "window.dashboardData = $jsonPayload;"

# 4. Overwrite data.js for immediate dashboard consumption
Set-Content -Path $jsOutputPath -Value $jsContent -Encoding UTF8

Write-Host "[SUCCESS] data.js updated successfully." -ForegroundColor Green
